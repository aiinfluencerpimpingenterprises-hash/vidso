Connect Vidso to Claude

Vidso exposes a remote MCP server so Claude (and Cursor) can run the long-form video pipeline: script, voiceover, B-roll, captions, and MP4 export. MCP is an open standard. This is a Vidso connector, not an Anthropic product.

Connector URL

https://api.vidso.pro/mcp

If your team hosts the MCP service on another domain, use that HTTPS origin plus /mcp. Set PUBLIC_BASE_URL on the server to match.

Claude Desktop / claude.ai

  1. Open Settings → Connectors.
  2. Add a custom connector named Vidso.
  3. Paste the MCP URL above.
  4. Connect and sign in with your Vidso account (email/password).
  5. Ask Claude to generate a long-form video. Requires Vidso credits or an active plan.

Cursor

  1. Open Cursor MCP / connector settings.
  2. Add a connector named Vidso with the same MCP URL.
  3. Authenticate with your Vidso account, then prompt the agent to generate a video.

CLI and other MCP clients may use a different config format. Prefer Streamable HTTP to /mcp with OAuth or a Bearer Vidso JWT.

Self-host / Vercel

The server lives in the mcp/ folder of the Vidso repo and deploys as a Next.js app on Vercel. Set PUBLIC_BASE_URL and OAUTH_SIGNING_SECRET, deploy from mcp/, then attach api.vidso.pro (or update this docs URL).
