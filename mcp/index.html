Frequently askedquestions

What is Vidso MCP?

Vidso MCP is a Streamable HTTP server at https://www.vidso.pro/mcp. Claude adds it as a custom connector, you sign in with your Vidso account, and Claude can call Vidso tools from chat.

How do I add Vidso as a Claude connector?

Open Claude settings, go to Settings → Connectors, add a custom connector named Vidso, and paste https://www.vidso.pro/mcp. Click Add, then Connect, and sign in with your Vidso account.

Do I need an API key?

No. Claude uses OAuth. When you click Connect, you sign in with your Vidso account. There is no separate Vidso API key product for this connector.

Which Vidso tools can my agent use?

Claude can run long-form script and render, thumbnails, clipping, ranking, commentary, reframe, voiceover, captions, video download lookup, stock B-roll search, My Files listing, account quota, and YouTube connect, list, update, and upload. Video Editor and Faceless Studio are not exposed over MCP.

Does it use my plan's limits?

Yes. Generation tools require an active Vidso plan and use the same long-form, short-form, and Faceless Studio credit limits as the app. vidso_account can show what is left. Account and catalog tools work without a paid-plan check at the MCP layer.

Where do my generated videos go?

Finished outputs land in My Files on the signed-in account. Claude can list them with files_list. If YouTube is connected, youtube_upload can publish a finished render to that channel.

Does it work on Plus, Pro, and Studio?

Yes. Any active plan can use the connector. Clipping analysis is a Pro+ feature. Video length and monthly quotas still follow the plan you are on.

What happens if my session expires?

The connector issues a short-lived access token (about 55 minutes) and a refresh token that lasts 30 days. When the session is no longer valid, Claude will ask you to connect and sign in again.
