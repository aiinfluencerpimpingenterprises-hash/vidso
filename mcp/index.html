    Frequently askedquestions

    What is Vidso MCP?

    Vidso MCP is a Streamable HTTP server at https://www.vidso.pro/mcp. Add that URL in your agent, sign in with your Vidso account over OAuth, and the agent can call Vidso tools from chat.

    How do I add Vidso as a Claude connector?

    Open Claude settings, go to Settings → Connectors, add a custom connector named Vidso, and paste https://www.vidso.pro/mcp. Click Add, then Connect, and sign in with your Vidso account.

    How do I connect Vidso to ChatGPT?

    In ChatGPT, go to Settings → Connectors. Enable developer mode if your plan requires it. Add a custom connector named Vidso, paste https://www.vidso.pro/mcp, then connect and sign in with your Vidso account.

    Can I use Vidso MCP in Cursor?

    Yes. In Cursor, open Settings → MCP & Integrations → New MCP server, paste the Vidso block into mcp.json, save, then approve the sign-in prompt with your Vidso account.

    Do I need an API key?

    No. The connector uses OAuth. When you connect, you sign in with your Vidso account. There is no separate Vidso API key product for this server.

    Can I connect more than one agent?

    Yes. The same URL works in any client that can add a Streamable HTTP MCP server and complete OAuth. Each connection signs in with your Vidso account, and credits and files stay on that account.

    Which Vidso tools can my agent use?

    The agent can run long-form script and render, thumbnails, clipping, ranking, commentary, reframe, voiceover, captions, video download lookup, stock B-roll search, My Files listing, account quota, and YouTube connect, list, update, and upload. Video Editor and Faceless Studio are not exposed over MCP.

    Does it use my plan's limits?

    Yes. Generation tools require an active Vidso plan and use the same long-form, short-form, and Faceless Studio credit limits as the app. vidso_account can show what is left. Account and catalog tools work without a paid-plan check at the MCP layer.

    Where do my generated videos go?

    Finished outputs land in My Files on the signed-in account. Your agent can list them with files_list. If YouTube is connected, youtube_upload can publish a finished render to that channel.

    What if my session expires?

    The connector issues a short-lived access token (about 55 minutes) and a refresh token that lasts 30 days. When the session is no longer valid, the agent will ask you to connect and sign in again.

    How do I install the Vidso CLI?

    Open the CLI tab and copy the macOS and Linux command or the Windows command. After it runs, use vidso login to sign in with your Vidso account in the browser.

    Which platforms does the CLI support?

    The CLI tab lists install commands for macOS, Linux, and Windows. The same Vidso account is used after vidso login.
